# 🐍 Máster Completo Python: De Cero a Experto

Repositorio dedicado a documentar mi aprendizaje de **Python** a través del curso **Máster Completo Python de Cero a Experto**, impartido por **Andrés Guzmán en Udemy**.

## 🎯 Objetivo

Aprender Python desde sus fundamentos hasta el desarrollo de aplicaciones backend modernas, aplicando buenas prácticas y desarrollando proyectos prácticos.

## 📚 Contenido

Durante el curso voy a trabajar con:

* Fundamentos de Python
* Estructuras de datos
* Programación Orientada a Objetos (POO)
* Patrones de diseño
* Manejo de archivos y datos
* NumPy y Pandas
* Bases de datos y SQLAlchemy
* Desarrollo web con Django
* APIs REST con FastAPI
* Autenticación con JWT
* WebSockets
* Docker
* Microservicios
* Kafka
* Aplicaciones de escritorio con Tkinter y PySide

## 🛠️ Tecnologías principales

`Python` · `FastAPI` · `Django` · `SQLAlchemy` · `Docker` · `Kafka` · `WebSocket` · `Pandas` · `NumPy`

## 📈 Progreso

Este repositorio irá creciendo a medida que avance en el curso, incluyendo ejercicios, ejemplos, apuntes y pequeños proyectos realizados durante el aprendizaje.
